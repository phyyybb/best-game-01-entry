# Deep Drop

An original deep-sea descent arcade game — pilot a tiny submersible into the trench, dodge
jellyfish, ambushing anglerfish and falling rock, collect glowing plankton, and see how deep
you can get before your hull gives out. Built for [make.fun's best-game-01 bounty](https://make.fun/c/best-game-01).

## Play

Serve the `game/` directory with any static server and open it in desktop Chrome:

```
node serve.ts        # http://localhost:8080
```

Steer with arrow keys / WASD, Space to dive, P to pause. Depth is your score.
